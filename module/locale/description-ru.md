# Map Editor Improvements

**Авторы**: Monsterfish, Heroesflorian

Расширяет редактор карт. Редактор ландшафта получает больше деревьев, камней, текстур, воды, высот и стад, а также счётчики карты. Режим замка получает больше зданий, руин и вариантов стен. Также добавлены настройки карты, отмена и повтор и сетка ресурсов. Каждая функция выключена, пока вы не включите её в настройках.
