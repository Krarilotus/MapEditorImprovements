# Map Editor Improvements

**Авторы**: Monsterfish, Heroesflorian

Расширяет информацию о карте в редакторе карт и добавляет недостающие инструменты: стадии роста деревьев, яблони, дополнительные кусты, поваленные деревья, гравий и железо, варианты камней, размеры стад и многое другое. Каждая функция выключена, пока вы не включите её в настройках.
