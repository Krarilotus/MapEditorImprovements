# Map Editor Improvements

**Author(s)**: Monsterfish, Heroesflorian

Extends the map editor. The landscape editor gets more trees, rocks, textures, water, heights
and herds, and counts of what the map holds. Castle mode gets more buildings, ruins and wall
variants. Also adds map settings, undo and redo, and a resource grid. Every part is off until
you switch it on in the settings.
