# Map Editor Improvements

**سازندگان**: Monsterfish, Heroesflorian

اطلاعات بیشتری دربارهٔ نقشه‌ای که در حال ساخت آن هستید در ویرایشگر نقشه نمایش می‌دهد و ابزارهایی را که ویرایشگر کم دارد اضافه می‌کند: مراحل رشد درختان، درخت سیب، بوته‌های بیشتر، درختان قطع‌شده، شن‌ریزه و آهن، گونه‌های صخره، اندازهٔ گله‌ها و بسیار بیشتر. هر بخش را می‌توان جداگانه در تنظیمات خاموش کرد.
