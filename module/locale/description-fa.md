# Map Editor Improvements

**سازندگان**: Monsterfish, Heroesflorian

ویرایشگر نقشه را گسترش می‌دهد. ویرایشگر چشم‌انداز درخت، صخره، بافت، آب، ارتفاع و گلهٔ بیشتر و شمارنده‌های نقشه می‌گیرد. حالت قلعه ساختمان، ویرانه و گونه‌های دیوار بیشتری می‌گیرد. تنظیمات نقشه، واگرد و از نو و شبکهٔ منابع نیز افزوده می‌شود. هر بخش تا وقتی آن را در تنظیمات روشن نکنید خاموش است.
